# Use AI with your work

To summarize one draft, send that document. To ask questions across a workspace, use Agent on desktop or approve a connection to your own AI app.

## Send one document

Open a Rich Text document and choose **More → Open in → ChatGPT** or **Claude**. With a longer document, Lunaris may copy the text to your clipboard for you to paste. The service receives the document text you send. Workspace access requires a separate connection.

## Ask Agent about selected resources

If **Agent** is available for your account, open it from the desktop app's navigation. Choose **Connect ChatGPT** and sign in with an eligible ChatGPT subscription. From an open workspace, choose **Agent Mini** to use the same conversation beside your work.

Type `@` in your message and select a resource to give Agent context. Agent shows proposed changes for review before applying them. Prompts and resource tool results go to the connected model provider.

## Connect an external AI app

Use MCP to let your AI app search or summarize across a workspace. Start with
read-only access. Follow the setup for Lunaris Cloud or the desktop app in
[Connect an AI app with MCP](/customize/mcp).
