# Audit and back up an organization

Organization owners can review administrative events and request a ZIP archive of synced organization content. Both actions need a connection.

## Investigate an access or settings change

1. Open **Organization Settings → Audit log**.
2. Filter by action, date, or outcome. If you know the account ID, add it as the **Actor ID**.
3. Open the event to review the actor, time, and outcome. Include the request ID when contacting support if one is shown.

For edits to one document, use [Version History](/teams/edit-together#see-how-a-document-changed).

## Download a backup

1. Ask editors to reconnect and confirm their [upload queues have cleared](/reference/sync-status).
2. Open **Organization Settings → Backups** and select **Create backup**.
3. When Lunaris sends the email, return to **Backups** and download the ZIP. Download it within 24 hours.

The archive covers organization content that reached cloud storage, including uploaded files. Export Local work and preserve unsynced content separately. Download and retain the ZIP for offline access to the archive. It cannot roll back the live organization.
