# Edit together

Open the same resource in a Private or Shared cloud workspace. Each contributor needs [edit access](/teams/share-a-workspace). Viewers can open the work without changing it.

## Work from two devices

1. Open the shared resource while online. Allow time for it to download on each device.
2. Make an edit. The other editor should see it without refreshing. Rich Text documents, Kanban boards, and Excalidraw drawings support collaborative editing.
3. If you lose internet access, keep editing on the device that has the resource. When you reconnect, Lunaris syncs queued changes and merges concurrent edits. Watch the [sync indicator](/reference/sync-status) before closing the app.

Two people can still make conflicting editorial decisions in the same passage. Coordinate ownership of closely related edits and review the result together.

## See how a document changed

In a Rich Text document, choose **More → Version History**. Select an entry to inspect its author, timing, and added or removed text. Use it to review changes. To recover wording, copy or reapply it yourself. This view does not restore an entire earlier version.
