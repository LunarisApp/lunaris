# Review Organization Activity

The Audit log gives organization owners a searchable record of important organization actions. Use it to investigate an unexpected change, review administration, or understand why an action was denied.

## Find an event

1. Open **Organization Settings → Audit log**.
2. Filter by action, outcome, or date. If you know a person’s account ID, enter it under **Actor ID**.
3. Apply the filters, then select an event for its details.

Outcomes are grouped as **Success**, **Failure**, or **Denied**. The details show who did what, when it happened, and whether it succeeded. Some events also include a reason and a request ID for support. Use **Load more** to review older events.

Start with a broad date range and outcome, then add an action or person’s account ID only if the list remains large. Clear the filters to return to recent activity.

The Audit log is an owner-only, online organization feature. It does not replace [Version History](/guides/writing-and-editing/version-history), which focuses on content changes inside one document.
