# Erste Schritte mit Lunaris

Erstellen Sie einen Arbeitsbereich, schreiben Sie eine kurze Notiz und prüfen Sie, ob sie sich offline öffnen lässt. Sie können die gesamte Anleitung als Gast durchgehen.

## 1. Speicherort des Arbeitsbereichs wählen

Öffnen Sie [Lunaris](https://web.lunaris.app) und wählen Sie **Als Gast fortfahren** oder melden Sie sich an. Wählen Sie unter **Zuletzt verwendet** den Eintrag **Erstellen → Leer erstellen**. Nennen Sie den Arbeitsbereich *Erste Notizen* und wählen Sie die Sichtbarkeit.

- **Lokal** speichert Ihre Arbeit in diesem Browser oder in der Desktop-App. Gäste verwenden diese Option.
- **Privat** synchronisiert Ihre Arbeit zwischen Geräten und ermöglicht die Freigabe für ausgewählte Mitglieder der Organisation.
- **Geteilt** synchronisiert Ihre Arbeit und macht sie für die gesamte Organisation zugänglich.

Wählen Sie für diese Übung **Lokal**. Wenn Sie sich später anmelden, bleibt der Arbeitsbereich auf dem ursprünglichen Gerät. Wenn Sie ein Projekt auf mehreren Geräten bearbeiten möchten, legen Sie von Anfang an einen Cloud-Arbeitsbereich an. Eine Übersicht finden Sie unter [Sichtbarkeit von Arbeitsbereichen](/de/reference/workspace-visibility).

Wählen Sie **Arbeitsbereich erstellen** und öffnen Sie die Karte unter **Zuletzt verwendet**. Ihre Organisation fasst Ihre Arbeitsbereiche zusammen und verwaltet die Mitgliedschaft. Ein Arbeitsbereich enthält die Dateien, Dokumente und weiteren Ressourcen eines Projekts.

## 2. Eine Notiz schreiben und erneut öffnen

1. Wählen Sie in der Seitenleiste **Datei hinzufügen → Rich Text**.
2. Nennen Sie das Dokument *Offline-Test* und schreiben Sie einen Satz. Lunaris speichert Änderungen während der Eingabe.
3. Schließen Sie den Dokument-Tab und öffnen Sie *Offline-Test* erneut über die Seitenleiste. Prüfen Sie, ob der Satz noch da ist.
4. Lassen Sie Lunaris geöffnet, trennen Sie die Netzwerkverbindung, ergänzen Sie einen weiteren Satz und öffnen Sie das Dokument erneut. Prüfen Sie, ob beide Sätze angezeigt werden. Stellen Sie die Verbindung anschließend wieder her.

Wenn Sie einen Cloud-Arbeitsbereich verwenden, öffnen Sie ihn zuerst online und warten Sie, bis die Dateien heruntergeladen sind. Unter [Offline arbeiten](/de/personal/work-offline) erfahren Sie, wie Sie Dateien vorbereiten und die Synchronisierung nach dem Wiederverbinden prüfen.
