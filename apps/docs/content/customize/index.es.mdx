# Personalizar un espacio de trabajo

Las extensiones se activan por espacio de trabajo. Puedes dedicar un espacio de escritura a borradores y fuentes o añadir un tablero y un dibujo a un espacio de proyecto. Al abrir un recurso, su extensión proporciona la vista en la que lo usas.

- [Gestiona las extensiones](/es/customize/manage-extensions) para activar una herramienta integrada, instalar una versión del catálogo o volver a acceder a contenido existente.
- [Configura un proyecto con notas, archivos y un tablero](/es/customize/tools-for-a-project).
- [Elige cómo usar una herramienta de IA](/es/customize/connect-ai), desde enviar un documento hasta conceder acceso a recursos concretos.
- [Conecta una aplicación de IA mediante MCP](/es/customize/mcp) para buscar y trabajar con los recursos que autorices.
- [Crea tu propia extensión](/es/developers/extensions) si necesitas una herramienta o un tipo de recurso nuevo.
