# Build extensions

Use the public TypeScript and React SDK to add capabilities to a Lunaris workspace. An extension can open a standalone tool, define a new resource type, or render a resource view. Start with a [working standalone panel](/developers/extensions/quickstart), then add only the contracts your workflow needs.

## Choose what to build

| Goal | Start here |
| --- | --- |
| Open a standalone tool from the workspace launcher | [Create your first extension](/developers/extensions/quickstart) |
| Save a new kind of content and give it an editor | [Resources and resource views](/developers/extensions/resources-and-views) |
| Choose collaborative, key-value, or file storage | [Storage and migrations](/developers/extensions/storage-and-migrations) |
| Add commands, search, networking, or exports | [Host capabilities](/developers/extensions/host-capabilities) |
| Test the installed behavior, then distribute a release | [Testing](/developers/extensions/testing) and [Publishing](/developers/extensions/publishing) |

A resource type defines the schema and storage slots. A resource is one saved instance. A resource view renders that instance and declares which slots it uses. A standalone view can run as a workspace tool without a resource target. External extensions run in a sandbox and request permissions for the host capabilities they need. See [Extension contracts](/developers/extensions/contracts).

## Version baseline

The SDK package version, manifest `api` range, sandbox protocol, and extension release version represent different contracts. Use the generated starter files and the target app to determine compatibility.

The SDK source supports manifest API 0.9 and 0.10 and sandbox protocols 6 and 7. A host release must support the API and protocol that your build uses. Check [runtime metadata for publishing](/developers/extensions/publishing#match-the-executables-protocol) and use the TypeScript definitions shipped with your installed SDK for exact signatures.

## Examples and reference

- [Community starter and examples](https://github.com/LunarisApp/extensions) show how to scaffold, package, and use key-value or Yjs storage.
- [Public SDK source](https://github.com/LunarisApp/lunaris/tree/main/packages/plugin-sdk) defines the extension contracts.
- [Built-in extension source](https://github.com/LunarisApp/lunaris/tree/main/extensions) shows Rich Text, Kanban, and File in use. Follow the public SDK entry points for external extensions.
