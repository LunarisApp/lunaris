# Export Workspace Content to PDF

Use **Exporter** to combine writing, boards, and drawings into a report or
other PDF.

1. Open **Settings → Manage extensions** in the workspace.
2. Install **Exporter** from the marketplace.
3. Select **Add file → Exporter** and create an export resource.
4. Open it and choose the sources to include.
5. Select **Export PDF**.

Lunaris saves your source selection so you can export it again later. The PDF
downloads when it is ready.

Only supported sources appear in the list. Uploaded files are not automatically
merged into the PDF. If a source fails, check the error shown in Exporter.

To export one document, use [Export and Copy Documents](/guides/writing-and-editing/export-and-copy-documents).
