# Entwicklung

- [Entwickeln Sie Erweiterungen](/de/developers/extensions), um einen Arbeitsbereich um ein Werkzeug, einen Ressourcentyp oder dessen Ansichten zu ergänzen. Die [Kurzanleitung](/de/developers/extensions/quickstart) zeigt, wie Sie ein eigenständiges Panel erstellen.
- [Verwenden Sie die CLI](/de/developers/cli), um Arbeitsbereiche und Ressourcen im Terminal abzufragen oder Aufgaben mit Skripten zu automatisieren.
- [Verwalten Sie Erweiterungen](/de/customize/manage-extensions), um eine vorhandene Version in einem Arbeitsbereich zu installieren oder zu aktualisieren.
