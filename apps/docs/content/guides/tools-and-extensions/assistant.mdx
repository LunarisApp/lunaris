# Use the Assistant

Luna is Lunaris's built-in assistant. It can help draft text, turn notes into actions, polish writing, and answer questions using workspace context.

## Start a conversation

Enable the **Assistant** extension, then open **Assistant** from the workspace's tools. Choose a starter prompt or write your own. Press <kbd>Enter</kbd> to send and <kbd>Shift</kbd><kbd>Enter</kbd> for a new line.

You can stop a response while it is being generated, retry it, or copy the finished response. Sources and reasoning appear when they are available.

## Give Luna context

Type `@` in the prompt to mention a workspace, folder, or resource. Search the list and select the exact context Luna should use. A focused mention usually produces a more relevant answer than asking about an entire organization.

You can also attach up to four images, JSON, CSV, Markdown, or text files. Attachments must stay under 600 KB in total.

Luna can use tools to search and read Lunaris content. If a requested action would change your content, Luna asks for approval in the chat first. Review the proposed action before allowing it.

The assistant needs an internet connection and may depend on your organization plan.
