## Résoudre un problème

- [Récupérez le travail local et rétablissez la synchronisation](/fr/reference/recover-local-work) si des éléments manquent hors ligne, si un envoi est bloqué ou si vous envisagez d’effacer les données.
- [Résolvez les problèmes de compte et d’accès](/fr/reference/account-and-access) si vous ne pouvez pas vous connecter, accepter une invitation ou ouvrir un espace de travail.
- [Résolvez les problèmes d’extension](/fr/reference/extension-problems) si un outil ou une vue de ressource manque, est désactivé ou ne s’ouvre pas hors ligne.
