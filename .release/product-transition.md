# Pending product changes at trunk cutover

Preserved from retired product Changesets. Include in first unified release.

## extension-contribution-hub

Link extension requests from the extensions page and group contribution links with the extension quickstart across all supported locales.

## trim-content-type-manifest

Adopt the Cordis extension runtime in desktop.

## resource-trash

Add recoverable resource trash with 30-day retention, restore, and permanent deletion. Extension hosts can now identify trashed workspace resources.

## modern-extensions

Rename Lunaris extension copy, source paths, manifests, and host components from plugin terminology to extension terminology. Extension manifests are now named `manifest.json`; existing protocol and storage identifiers remain compatible.
