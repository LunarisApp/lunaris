# Développeurs

- [Créez des extensions](/fr/developers/extensions) pour exécuter un outil ou ajouter un type de ressource et ses vues. Le [guide de démarrage rapide](/fr/developers/extensions/quickstart) vous aide à créer un panneau autonome.
- [Utilisez la CLI](/fr/developers/cli) pour interroger les espaces de travail et les ressources depuis un terminal ou automatiser des tâches avec des scripts.
- [Gérez les extensions](/fr/customize/manage-extensions) pour installer ou mettre à jour une version dans un espace de travail.
