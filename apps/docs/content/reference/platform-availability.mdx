# Platform availability

| Platform | How to open Lunaris | Local work |
| --- | --- | --- |
| Computer browser | Visit [web.lunaris.app](https://web.lunaris.app). | Stays in the browser profile. |
| Phone or tablet | Use the web app. Open a resource full screen and use Back to return to the workspace. | Stays in the browser or installed web app on that device. |
| Installed web app | Use your browser's app installation or Add to Home Screen option, where supported. | Still depends on browser storage. |
| Desktop app | Install the [desktop preview](https://lunaris.app/downloads). Apply updates manually. | Stays in the desktop app. Supports approved [local AI connections](/customize/mcp#connect-to-the-desktop-preview). |

For the same synced workspace on a second device, use **Private** or **Shared** and sign in to the same account and data region. [Open the workspace and needed files online](/personal/work-offline) before planning to work offline on that device.
