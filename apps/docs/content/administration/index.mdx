# Administration

An organization is the boundary for membership, billing, and backups. Workspace access sits inside that boundary. Decide where your team will host its synced work, then use workspace visibility and roles to control who can open it.

- [Manage an organization](/administration/manage-organization), including member access and billing.
- [Audit activity and back up cloud work](/administration/audit-and-backup).
- [Choose how to host Lunaris](/administration/hosting) and check which data regions are available.
- [Compare roles and permissions](/reference/roles-and-permissions).
