# Back Up an Organization

Organization owners can download a ZIP backup of content saved in Lunaris Cloud.

## Create a backup

1. Make sure every device has finished syncing.
2. Open **Organization Settings → Backups**.
3. Select **Create backup**.

The archive includes organization details, members, workspaces, documents, extension content, and uploaded files that have reached cloud storage. It does not include local workspaces or changes still waiting in a device's upload queue.

Lunaris prepares the backup in the background. You can leave the page; an email is sent when the archive is ready. Return to **Backups** and select **Download**.

The download is available for 24 hours. Save the ZIP somewhere safe. After it expires, request a new backup.

An organization backup protects against loss and supports data portability, but it is not an in-app restore point. Keep the downloaded archive; creating one does not replace the current organization or roll it back.
