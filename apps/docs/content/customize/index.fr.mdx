# Personnaliser un espace de travail

Les extensions s’activent par espace de travail. Réservez un espace d’écriture aux brouillons et aux sources, ou ajoutez un tableau et un dessin à un espace de projet. Lorsque vous ouvrez une ressource, son extension fournit la vue dans laquelle vous l’utilisez.

- [Gérez les extensions](/fr/customize/manage-extensions) pour activer un outil intégré, installer une version du catalogue ou retrouver du contenu existant.
- [Préparez un projet avec des notes, des fichiers et un tableau](/fr/customize/tools-for-a-project).
- [Choisissez comment utiliser un outil d’IA](/fr/customize/connect-ai), de l’envoi d’un document à l’autorisation d’accéder à certaines ressources.
- [Connectez une application d’IA via MCP](/fr/customize/mcp) pour rechercher et utiliser les ressources que vous autorisez.
- [Créez votre propre extension](/fr/developers/extensions) si vous avez besoin d’un nouvel outil ou type de ressource.
