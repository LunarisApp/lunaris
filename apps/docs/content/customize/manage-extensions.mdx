# Manage extensions

Choose tools for the workspace you are in. Owners and editors can change this setup. Viewers can open the tools and resources already available to them.

## Enable a built-in tool

Open **Settings → Manage extensions** or choose **Explore extensions** from an empty panel. Find the built-in extension and enable it. Its tools or resource types become available in that workspace. For a concrete setup, [add files, a board, and a drawing](/customize/tools-for-a-project).

## Install or update a marketplace extension

1. With an internet connection, find the extension in **Manage extensions**.
2. Check the publisher, release, and requested permissions. Select **Install** if you trust it, then reload when prompted.
3. Use the same panel to choose a compatible update or to uninstall. The installation belongs to this workspace.

## Reopen content when its extension is disabled

Disabling an extension removes its controls and keeps the resources it created. If a resource shows **Extension Required**, re-enable the extension in that workspace to restore its resource view. For missing or incompatible releases, see [Extension problems](/reference/extension-problems).

Installing and updating marketplace releases requires a connection. Built-in toggles and uninstall are available offline.
