# Tabs, Panels, and Windows

Each document, board, drawing, file, or tool opens in a tab. You can keep several tabs in one panel or arrange panels side by side.

## Arrange your workspace

- Select an resource in the workspace tree to open it.
- Drag a tab to reorder it.
- Drag a tab toward an edge of the editor to place it in a new panel.
- Select the **+** button in an empty panel to create content or explore extensions.

The active tab is reflected in the page URL, so you can copy a direct link to it.

## Manage tabs

Open a tab's context menu to **Close**, **Close Others**, or **Close All**. You can also choose **Move to New Window** to place that panel in a separate browser window.

Your browser may ask permission to open the new window. If nothing happens, allow pop-ups for Lunaris and try again.

Closing the separate window returns its panel to the main workspace when possible.
