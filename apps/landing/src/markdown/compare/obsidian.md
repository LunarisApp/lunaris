# Lunaris vs Obsidian

Lunaris supports real-time co-editing in shared workspaces. Team members can have different access roles, and offline edits sync when they reconnect.

Obsidian organizes Markdown files in local vaults. Obsidian Sync can share a vault and sync changes between collaborators.

See the [Obsidian import guide](https://docs.lunaris.app/guides/organizing-workspaces/import-from-obsidian) to move an existing vault to Lunaris.
