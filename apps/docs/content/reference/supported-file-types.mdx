# Supported File Types

The File extension lets you keep source material inside a workspace. Supported
uploads stay in their original format and can be downloaded again later.

## Upload and preview

| Kind | File types | Preview in Lunaris |
| --- | --- | --- |
| Documents | `.pdf`, `.docx` | Yes |
| Presentations | `.pptx` | Yes |
| Spreadsheets | `.xlsx` | Yes |
| Images | `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif` | Yes |
| Plain text | `.txt` | Yes |
| Markdown | `.md` | Yes |
| Structured text | `.csv`, `.json`, `.xml` | Yes |

These formats can be selected from **Add file → File** when the File
extension is enabled. The preview is for reading the uploaded file; it does not
convert the file into an editable Lunaris document.

An uploaded file can remain useful even if its preview cannot load. Open the
file's **More** menu and choose **Download** to save the original file to your
device.

## Document export

Documents created with the Rich Text extension can be exported as:

- **PDF** for a fixed-layout copy; or
- **Markdown (`.md`)** for portable, editable text.

The marketplace-installed Exporter extension can also combine supported workspace resources into one PDF.
Uploaded files are not automatically merged into the PDF.

## Workspace import

**Import from Obsidian** accepts a folder or vault and converts `.md` and
`.markdown` notes into editable documents. It preserves supported folders and
keeps supported source files in an **Original Files** folder. Hidden and
unsupported files are skipped, and the import summary shows the result before
the workspace is created.

See [Add and Preview Files](/guides/tools-and-extensions/add-and-preview-files),
[Export and Copy Documents](/guides/writing-and-editing/export-and-copy-documents),
or [Import from Obsidian](/guides/organizing-workspaces/import-from-obsidian) for
instructions.
