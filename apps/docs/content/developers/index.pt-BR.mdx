# Desenvolvedores

- [Crie extensões](/pt-BR/developers/extensions) para executar uma ferramenta ou adicionar um tipo de recurso e suas visualizações. Siga o [guia de início rápido](/pt-BR/developers/extensions/quickstart) para criar um painel independente.
- [Use a CLI](/pt-BR/developers/cli) para consultar espaços de trabalho e recursos pelo terminal ou automatizar tarefas com scripts.
- [Gerencie extensões](/pt-BR/customize/manage-extensions) para instalar ou atualizar uma versão em um espaço de trabalho.
