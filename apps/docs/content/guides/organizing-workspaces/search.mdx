# Search Lunaris

Global Search helps you move around Lunaris without browsing every folder.

## Open Global Search

Select **Search** in the app or press <kbd>⌘</kbd><kbd>K</kbd> on macOS and <kbd>Ctrl</kbd><kbd>K</kbd> on Windows and Linux.

Start typing to find:

- recent resources;
- workspaces in the current organization;
- resources in the current workspace;
- matching text inside documents;
- Lunaris commands.

Use the arrow keys to move through results, press <kbd>Enter</kbd> to open one, or press <kbd>Esc</kbd> to close search.

## Search a smaller area

Global Search is not the only search field:

- In **Recent Workspaces**, use workspace search and sort by recent activity or name.
- In an open workspace, use the field above the workspace tree to filter resources by name.

Content matches search the text of documents. Uploaded file contents and every extension resource are not necessarily included, so search by the resource's name when a content match does not appear.
