# Use Focus Mode

Focus Mode gives the active resource more room and hides the surrounding workspace interface. It is useful for long writing sessions, presentations, or reviewing a drawing without distractions.

## Enter Focus Mode

1. Open the resource you want to focus on.
2. Open the **More** menu in its header.
3. Choose **Focus Mode**.

You can also press <kbd>⌘</kbd><kbd>Shift</kbd><kbd>F</kbd> on macOS or <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>F</kbd> on Windows and Linux.

Focus Mode applies to the active panel. If you have several resources open side by side, select the one you want first.

## Exit Focus Mode

Press <kbd>Esc</kbd> to return to the full workspace view. Your tabs and panel arrangement remain in place.

Focus Mode is available in layouts with enough screen space. On a narrow mobile layout, Lunaris already simplifies the interface, so the option may not appear.
