# Create Kanban Boards

Kanban boards turn a workspace into a visual workflow. Use them for tasks, editorial calendars, research stages, or any process that moves through clear steps.

## Create a board

1. Enable the **Kanban** extension for the workspace.
2. Select **Add file**, then **Kanban**.
3. Name and create the board.

New boards include a **Status** property with Backlog, To Do, In Progress, Done, and Canceled columns.

## Add and move cards

Select **Add Task** in the toolbar, or add a card directly inside a column. Open a card to edit its title and description and review who created it and when.

Drag cards between columns to change their status, or drag within a column to reorder them. Columns can be collapsed when you need more room.

## Adapt the board

Use **Manage properties** to add fields such as labels, people, dates, text, numbers, checkboxes, or links to other resources. For labels, add and color the options you need. Use **Group by** to choose how the board groups cards.

Switch to **List** view when you want a compact table of cards and their properties. Both views show the same tasks, so changing one updates the other.

Boards save automatically and can be edited together in cloud workspaces.
