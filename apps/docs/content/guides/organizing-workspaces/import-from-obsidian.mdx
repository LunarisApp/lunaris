# Import from Obsidian

Lunaris can create a workspace from an Obsidian vault or another folder of Markdown notes.

## Import a vault

1. Go to **Recent Workspaces** and select **Create**.
2. Choose **Import from Obsidian**.
3. Select the vault folder from your device.
4. Review the import summary, choose the workspace name and visibility, then start the import.

Lunaris preserves supported folders and converts `.md` and `.markdown` notes into editable documents. It also keeps supported original files in an **Original Files** folder, including the original Markdown files.

Hidden folders and files—such as `.obsidian`, `.git`, and `.trash`—are skipped. Unsupported files are skipped too; the preview shows how many resources will be converted, copied, or skipped before you continue.

Import creates a new workspace and does not change the folder on your device. Markdown formatting is converted where possible, but app-specific Obsidian syntax or extensions may not have a direct Lunaris equivalent. Review a few notes after the import completes.
