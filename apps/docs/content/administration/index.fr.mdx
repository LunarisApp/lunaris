# Administration

L’organisation regroupe les membres et gère la facturation et les sauvegardes. L’accès se règle pour chaque espace de travail. Décidez où héberger le travail synchronisé, puis utilisez la visibilité et les rôles pour déterminer qui peut l’ouvrir.

- [Gérez une organisation](/fr/administration/manage-organization), notamment l’accès des membres et la facturation.
- [Consultez l’activité et sauvegardez le travail dans le cloud](/fr/administration/audit-and-backup).
- [Choisissez comment héberger Lunaris](/fr/administration/hosting) et consultez les régions de données disponibles.
- [Comparez les rôles et les autorisations](/fr/reference/roles-and-permissions).
