# Create Drawings with Excalidraw

The Excalidraw extension adds a freeform canvas to a Lunaris workspace. Use it for diagrams, wireframes, mind maps, annotated sketches, and visual notes.

## Create a drawing

1. Install **Excalidraw** from **Settings → Manage extensions**, or enable it if it is already installed.
2. Select **Add file**, then **Excalidraw**.
3. Name and create the drawing.

Use Excalidraw's toolbar to add shapes, arrows, lines, text, and freehand marks. Select elements to move, resize, group, or restyle them. The canvas follows your Lunaris light or dark theme.

Changes save automatically. In a shared cloud workspace, editors can work on the drawing together; viewers open it in view-only mode.

The status bar shows how many elements the drawing contains. Use [Focus Mode](/guides/writing-and-editing/focus-mode) when you want more space for the canvas.

Excalidraw drawings can also be selected as sources in [Export Workspace Content to PDF](/guides/tools-and-extensions/compile-to-pdf).
