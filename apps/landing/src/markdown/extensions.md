# Lunaris extensions

Extensions add tools to individual workspaces, including boards, drawings, file previews, and PDF export.

## Manage workspace extensions

1. Open **Settings → Manage extensions** in a workspace.
2. Enable a built-in extension or select **Install** on a compatible catalog release.
3. Use the same panel to update or uninstall catalog extensions. Turn built-in tools on or off per workspace.

Owners and editors can change the extension setup. Installing or updating catalog extensions requires a connection. Built-in toggles work offline. Disabling an extension preserves the content it created.
