# Add and Preview Files

The File extension keeps source material beside the documents, boards, and drawings that use it.

## Add files

1. Make sure **File** is enabled in the workspace's extensions.
2. Select **Add file** in the workspace tree.
3. Choose **File**.
4. Select one or more files from your device.

Lunaris previews common images, PDFs, plain text, Markdown, CSV, JSON, XML,
DOCX, PPTX, and XLSX files.

## Preview and download

Select an uploaded file in the workspace tree to preview it. Preview controls depend on the file type: images and PDFs are displayed visually, while supported text and office files are rendered in a readable view.

If a format cannot be previewed, the file still remains in the workspace. Open its **More** menu and choose **Download** to save a copy to your device.

Files in a cloud workspace upload and sync like other workspace content. Open important files while online before relying on them offline; a file that has not yet downloaded to this browser may need a connection before it can be previewed.
