# Export your work

Export important Local work before clearing browser data, reinstalling Lunaris, or replacing the device. Save the exported files somewhere outside the app.

## Export one document or copy its text

Open the document and choose **More → Export as → PDF** for a finished copy or **Markdown** for editable text you can take into another app. Choose **More → Copy page** to put Markdown on your clipboard. Download uploaded files separately from the file's **More** menu.

## Assemble a report from several resources

Use the **Exporter** marketplace extension to combine supported documents, boards, and drawings:

1. [Install Exporter](/customize/manage-extensions) in the workspace.
2. Choose **Add file → Exporter** and open the new export resource.
3. Select the sources to include and choose **Export PDF**.

The export resource remembers its sources for next time. Uploaded files do not appear as sources unless supported by the exporter. For an archive of synced organization content, see [Audit and back up an organization](/administration/audit-and-backup).
