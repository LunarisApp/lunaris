# Platform Availability

| Platform | Status |
| --- | --- |
| Computer browser | Available at [web.lunaris.app](https://web.lunaris.app). |
| Phone or tablet browser | Available, with a layout for smaller screens. |
| Installed web app | Supported browsers can install it or add it to the home screen. |
| Desktop app | Preview; requires manual updates. |
| Dedicated mobile app | Planned. Use the web app for now. |

An installed web app still uses browser storage. The desktop preview has its own
local data. Local workspaces do not move between them automatically.

Private and Shared workspaces sync through your account. Open them online on
each device before relying on them offline.

See [Web, Desktop, and Mobile](/getting-started/web-desktop-and-mobile) for setup
and [Work Offline](/guides/offline-and-sync/work-offline) for preparation.
