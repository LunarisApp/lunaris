# Workspace Unavailable Offline

**Workspace unavailable offline** means this browser knows about the cloud
workspace, but has not downloaded the workspace data needed to open it. Nothing was
deleted from Lunaris Cloud.

## Open the workspace again

1. Reconnect to the internet.
2. Return to the organization's workspace list.
3. Open the workspace while connected.
4. Keep Lunaris open while it downloads.
5. Open the folders, resources, and uploaded files you expect to need offline.
6. Confirm the sync indicator is healthy before disconnecting again.

If the workspace still does not open while online, reload Lunaris once. Then
check [Sign-In and Access Problems](/troubleshooting/sign-in-and-access) in case
the account, organization, or workspace access changed.

## Why another device can open it

Offline availability is prepared separately in every browser profile. Opening
a workspace on one computer does not automatically download it to your phone,
another browser, or an installed web app. Sign in and open the workspace online
once on each browser where you want to use it offline.

Uploaded files may also need to download before their previews work offline.
Open important files while connected instead of assuming every attachment has
already reached the browser.

## If you are already offline

Lunaris cannot download a missing cloud workspace without a connection. Choose
**Back to workspaces** and work in another workspace that is already available, or
reconnect before opening this one.

Do not purge local data to fix this message. Purging removes other downloaded
workspaces and local work, making more content unavailable offline.

## Local workspaces are different

A Local workspace exists only in the browser profile where it was created. If it
is missing in another browser or device, connecting will not download it. Return
to the original browser profile to access it.

See [Work Offline](/guides/offline-and-sync/work-offline) for preparation steps.
