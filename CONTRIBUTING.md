# Contributing

Report bugs with steps to reproduce and expected behavior. For larger changes,
[open an issue](https://github.com/LunarisApp/lunaris/issues) to discuss the approach first.

Keep pull requests focused, explain what changed and why, and run the relevant
[development checks](DEVELOPMENT.md#useful-commands).

See the [development guide](DEVELOPMENT.md) for local setup. Report vulnerabilities
privately using the [security policy](SECURITY.md).
