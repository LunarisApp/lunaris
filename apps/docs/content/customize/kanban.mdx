# Track tasks with Kanban

Keep tasks next to the drafts and files they depend on. You need edit access to create a board and update its tasks.

## Create a board and move a task

1. In the workspace tree, choose **Add file → Kanban** and open the board. If **Kanban** is missing, [enable it in the workspace](/customize/manage-extensions#enable-a-built-in-tool).
2. Choose **Add Task**, enter a title, and set **Status**. For example, put *Review the draft* in **To Do**.
3. Drag the task to **In Progress** when you start, then to **Done** when you finish. You can also open the task and change its **Status** directly.

Use **List view** in the board toolbar to see the same tasks in a compact list. Switch back with **Kanban view**.

## Add fields and group tasks

1. In the board toolbar, open **Manage properties → Add property**.
2. Choose **Date** for a deadline, **People** for an assignee, or **Resource** for a draft or brief. Name the property, then open a task to set its value.
3. To group by something other than status, create a **Select** property and add its options. For example, create *Priority* with *High* and *Normal*. Choose **Priority** from **Group by** to see tasks by priority.

Dragging a task between columns updates the property selected in **Group by**.
