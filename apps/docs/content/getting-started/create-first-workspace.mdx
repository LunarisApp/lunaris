# Create Your First Workspace

A workspace keeps a project’s writing, folders, files, and other resources together.

## Create an empty workspace

1. Open your organization's **Recent Workspaces** page.
2. Select **Create**.
3. Choose **Create empty**.
4. Enter a workspace **Name**.
5. Review the **Slug**. Lunaris creates one from the name, and you can edit it
   before creating the workspace. The slug identifies the workspace in its web
   address and must be unique in the organization.
6. Choose a **Visibility**:
   - **Local** keeps the workspace on this device.
   - **Private** syncs it and limits access to people you grant access.
   - **Shared** syncs it for all organization members.
7. Select **Create Workspace**.

The dialog closes when the workspace is ready. Select its card in **Recent
Workspaces** to open it.

> Local workspace visibility cannot be changed later. Choose Private or Shared
> when you expect to use the workspace on another device or with other people.

## Add your first document

An empty workspace opens with the workspace sidebar and a blank panel.

1. In the blank panel, select **Create new file**. You can also use the add-file
   button at the top of the workspace sidebar.
2. Choose **Rich Text** to create a document.
3. Enter a name for the document.
4. Start writing in the editor.

Your document appears in the workspace sidebar. Select it whenever you want to
open it again.

## Add a folder

Select the add-folder button at the top of the workspace sidebar. Lunaris creates
a new folder and lets you name it immediately.

To create content inside a folder, select the folder before using the add-file
or add-folder button. You can also drag existing resources into folders.

## Import existing Markdown instead

If you already have an Obsidian vault or a folder of Markdown files, select
**Create**, then **Import from Obsidian** on the **Recent Workspaces** page. Choose
the folder, review the import summary, name and visibility, then select
**Import Workspace**.

Lunaris converts supported Markdown documents and preserves the folder
structure. See [Import from Obsidian](/guides/organizing-workspaces/import-from-obsidian)
for details.

## Find the workspace later

Return to **Recent Workspaces**. Search workspaces by name,
sort them by activity or name, and switch between grid and list views. Inside
another workspace, select the current workspace name in the top bar to switch
without returning home.
