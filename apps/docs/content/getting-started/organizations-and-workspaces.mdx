# Organizations and Workspaces

Lunaris organizes work in three levels:

- **Organization:** your workspaces, people, billing, and backups.
- **Workspace:** one project, with its own sharing settings and tools.
- **Resources:** the folders, documents, boards, tasks, drawings, and files in that workspace.

For example, a team organization could have a workspace for each client, with
folders for meeting notes, plans, and reference files.

## Use an organization for a separate group

Your **Personal** organization is for your own work and cannot have other
members. Create another organization for a team or client group.

On **Recent Workspaces**, select the organization name to switch organizations
or choose **Create new**. Use the settings button beside the name to manage it.

## Use a workspace for a project

Keep related work together in one workspace. Create separate workspaces when
projects need different people or tools.

Each workspace has its own [visibility](/getting-started/local-private-and-shared)
and [extensions](/guides/tools-and-extensions/manage-extensions).

## Use folders to organize resources

Folders can contain resources and other folders. Select a resource to open it;
drag it into a folder to move it within the workspace.
