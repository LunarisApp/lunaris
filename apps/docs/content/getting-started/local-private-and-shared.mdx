# Local, Private, and Shared Workspaces

Choose a workspace's **Visibility** when you create it:

| Visibility | Syncs across devices? | Who can open it? |
| --- | --- | --- |
| **Local** | No | People with access to this browser or app on this device. |
| **Private** | Yes | You and organization members you add. |
| **Shared** | Yes | Everyone in the organization. |

## Local: keep work on one device

Guests can only create Local workspaces. Signed-in users can choose Local too.

Local workspaces cannot be shared, included in cloud backups, or changed to
Private or Shared later. Signing up does not change this. Export your writing
and download important files before clearing local data or replacing your device.

## Private: choose who has access

Use Private for work you want on several devices or want to share with selected
people. The workspace owner can add organization members as **Editor** or
**Viewer** in workspace settings.

[Invite someone to the organization](/guides/collaboration/invite-and-share)
before adding them to a Private workspace.

## Shared: include the whole organization

Use Shared for work everyone in the organization should see. Organization Owners
and Editors can edit it; Viewers can read it.

## Change access later

With the required permission, open **Workspace Settings → Visibility** to change
between Private and Shared.

Changing Shared to Private removes organization-wide access. Add anyone who
should keep access using the private sharing controls.

If only Local is available when creating a workspace, sign in or create an
account to use cloud workspaces.
