# Write and Format Documents

Use Rich Text for notes, drafts, and longer writing. Your document saves automatically.

## Create a document

1. Open a workspace.
2. Select **Add file** in the workspace tree.
3. Choose **Rich Text**, name it, then create it.

Lunaris starts the document with a heading based on its name. Renaming the resource later does not rewrite your content.

## Format your writing

Type `/` on an empty line to choose a block such as a heading, list, quote, or code block. Select text to make it bold or italic, add a link, or change its style.

A block is a paragraph, heading, list, or similar part of your writing. Use the handle beside it to move it or change its type. Standard keyboard shortcuts such as undo, redo, bold, and italic also work.

The status bar shows the document's word and character counts. Your edits are saved automatically; cloud workspaces sync them when a connection is available.

For a distraction-free writing surface, see [Use Focus Mode](/guides/writing-and-editing/focus-mode).
