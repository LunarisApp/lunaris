# Keyboard Shortcuts

Lunaris uses <kbd>⌘</kbd> on macOS and <kbd>Ctrl</kbd> on Windows and Linux for
most shortcuts. Shortcuts only run when their action is available in the
current view.

## General

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Open Global Search | <kbd>⌘</kbd><kbd>K</kbd> | <kbd>Ctrl</kbd><kbd>K</kbd> |
| Open Settings | <kbd>⌘</kbd><kbd>,</kbd> | <kbd>Ctrl</kbd><kbd>,</kbd> |
| Copy selected resources | <kbd>⌘</kbd><kbd>C</kbd> | <kbd>Ctrl</kbd><kbd>C</kbd> |
| Paste copied resources | <kbd>⌘</kbd><kbd>V</kbd> | <kbd>Ctrl</kbd><kbd>V</kbd> |
| Delete selected resource | <kbd>⌘</kbd><kbd>Backspace</kbd> | <kbd>Delete</kbd> |

## Navigation

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Open Home | <kbd>Control</kbd><kbd>1</kbd> | <kbd>Alt</kbd><kbd>1</kbd> |
| Open Workspaces | <kbd>Control</kbd><kbd>2</kbd> | <kbd>Alt</kbd><kbd>2</kbd> |

## Workspaces

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Open Explorer | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>E</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>E</kbd> |
| Open Extensions | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>X</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>X</kbd> |
| Open Debugger | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>D</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>D</kbd> |
| Open a new tab | <kbd>⌘</kbd><kbd>N</kbd> | <kbd>Ctrl</kbd><kbd>N</kbd> |
| Close active tab | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>W</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>W</kbd> |
| Move active panel to a new window | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>N</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>N</kbd> |
| Rename selected resource | <kbd>F2</kbd> | <kbd>F2</kbd> |
| Toggle Focus Mode | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>F</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>F</kbd> |

Press <kbd>Esc</kbd> to leave Focus Mode. Copy, paste, rename, and delete act on
resources selected in the workspace tree, not text selected inside a document.

## Customize shortcuts

Open **Settings → Keybindings** to see the active binding for every action.
Choose **Edit** beside an action, then press the new key combination.

Lunaris warns when a binding conflicts with another action. Choose **Reset** to
restore one default or **Reset all to defaults** to restore every shortcut.
Browser shortcuts may also conflict with Lunaris keybindings. Custom
keybindings are stored in the current browser, so another browser or device can
use different bindings.
