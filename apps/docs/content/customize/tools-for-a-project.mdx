# Set up tools for a project

Set up a workspace for a research or writing project. Keep the brief, task board, and draft close enough to use together.

## Add the brief and track the work

1. Open **Settings → Manage extensions**. Enable **File** and **Kanban**.
2. In the workspace tree, choose **Add file → File** and select a brief or source material. Open it to preview it. If Lunaris cannot preview a format, use **More → Download** to open it in another app. See [Supported file types](/reference/supported-file-types).
3. Choose **Add file → Kanban** to make a board. Add a few tasks and drag them between status columns as the project progresses.
4. If you need a deadline, owner, or link back to a source, use **Manage properties**. Switch to **List** for a compact view of the same tasks and fields.

## Sketch and review beside your writing

Install **Excalidraw** through **Manage extensions**, then choose **Add file → Excalidraw**. Use the drawing to sketch an outline or compare alternatives. Open the draft and drag the drawing's tab to the edge of the editor to see both together.

In cloud workspaces, collaborators with edit access can edit boards and drawings. For work you need offline, [open the workspace, files, and installed tools while connected](/personal/work-offline).
