# Desarrolladores

- [Crea extensiones](/es/developers/extensions) para ejecutar una herramienta o añadir un tipo de recurso y sus vistas. Sigue la [guía de inicio rápido](/es/developers/extensions/quickstart) para crear un panel independiente que funcione.
- [Usa la CLI](/es/developers/cli) para consultar espacios de trabajo y recursos desde una terminal o automatizar tareas con scripts.
- [Gestiona las extensiones](/es/customize/manage-extensions) si ya tienes una versión y quieres instalarla o actualizarla en un espacio de trabajo.
