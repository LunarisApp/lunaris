# Team work

Create a team organization when several people need to work together. Use **Shared** for a team handbook or a project anyone in the organization should be able to find. Use **Private** when only selected members should see the work.

- [Share a workspace](/teams/share-a-workspace) with the organization or individual members.
- [Edit together](/teams/edit-together), resume after a connection drop, and review document history.
- [Compare roles](/reference/roles-and-permissions) before assigning access.
- [Manage the organization](/administration) if you own membership, billing, or backups.
