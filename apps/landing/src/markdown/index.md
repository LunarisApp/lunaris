# Lunaris

Lunaris is an offline-first word processor for writing, organizing resources, and collaborating in real time. Start with the editor and add tools such as Kanban boards, drawings, spreadsheets, and PDF export through extensions.

## Workspaces and data

An organization contains workspaces and members. A workspace holds the resources for a project, such as folders, documents, boards, and uploaded files.

- Local workspaces keep their content on one device.
- Private workspaces sync and are accessible to their owner and individually invited organization members.
- Shared workspaces sync and are accessible to every organization member, with editing controlled by their roles.

Keep editing synced workspaces offline. Changes sync when you reconnect, and teammates can edit the same shared document in real time while connected.

## Extend a workspace

Enable built-in tools in each workspace, install community extensions, or build private tools for your team. Use an approved MCP connection to give an AI client access within your permissions.
