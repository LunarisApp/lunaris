# Manage Extensions

Extensions add tools to a workspace, such as boards, drawings, file previews, an assistant, or PDF exports.

## Open the extension list

In a workspace, open **Settings** and choose **Manage extensions**. You can also choose **Explore extensions** from an empty panel.

The workspace extension store shows built-in and marketplace extensions together. Use search or open a card to see its description, developer, screenshots, links, and available versions.

Built-in extensions are always installed. Enable one to add its resource types or tools to the workspace, and disable it when the workspace no longer needs it.

Marketplace extensions belong only to the current workspace. Choose **Install**, confirm that you trust the extension, and reload when Lunaris asks. An installed extension can be updated to another compatible version or uninstalled from the same panel.

Disabling an extension removes its controls from the current workspace but does not delete the content it created. Re-enable the extension to work with that content again.

Editors and owners can manage workspace extensions. Viewers can see enabled content but cannot change the extension setup. Installing and updating marketplace extensions requires a connection; built-in toggles and uninstall remain available offline. Some releases may be unavailable for the current app version or plan.
