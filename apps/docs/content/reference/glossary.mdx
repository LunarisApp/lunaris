# Lunaris Glossary

| Term | Meaning |
| --- | --- |
| **Audit log** | A record of organization actions, available to its owner in Organization Settings. |
| **Cloud workspace** | A Private or Shared workspace that syncs through your account. |
| **Document** | Writing created with **Rich Text**. It can include headings, lists, links, and other formatting. |
| **Editor** | Someone who can change content. An organization Editor can also manage Shared workspaces. A Private workspace can grant Editor access separately. |
| **Extension** | A tool added to a workspace, such as a board, drawing, or assistant. Marketplace extensions are installed per workspace. |
| **File** | An upload kept in its original format. Previewing it does not turn it into editable Lunaris writing. |
| **Folder** | A way to group resources and other folders inside a workspace. |
| **Guest account** | A way to try Lunaris without signing up. Guest workspaces stay on the device. |
| **Local Data** | Settings for saved data on this device, pending uploads, and sync recovery. |
| **Local workspace** | A workspace saved only in the browser or app where you created it. It cannot sync, be shared, or change visibility later. |
| **Organization** | A group of workspaces with shared membership, billing, and backups. Your Personal organization is for you alone. |
| **Owner** | The person who manages an organization or a Private workspace. These are separate roles. |
| **Panel** | An area containing tabs. You can arrange panels side by side. |
| **Private workspace** | A cloud workspace available to its owner and selected organization members. |
| **Resource** | Content in a workspace: a folder, document, board, task, drawing, or file. |
| **Resource view** | How an opened resource appears, such as a board or writing editor. |
| **Shared workspace** | A cloud workspace available to everyone in its organization. Their organization roles control editing. |
| **Sync** | Keeping cloud workspaces updated across devices. Local workspaces never sync. |
| **Tab** | An open resource or tool inside a panel. |
| **Trash** | Resources deleted from the workspace sidebar, recoverable for 30 days. |
| **Viewer** | Someone who can read content without changing it. |
| **Visibility** | The Local, Private, or Shared setting that controls storage and access. |
| **Workspace** | A project inside an organization, with its own resources, tools, and sharing settings. |

For connection messages such as **You Are Offline**, see [Sync Status](/reference/sync-status).
