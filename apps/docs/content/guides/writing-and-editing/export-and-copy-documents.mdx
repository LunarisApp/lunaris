# Export and Copy Documents

Lunaris can turn a document into a portable file or copy it as Markdown.

## Export one document

1. Open the document.
2. Open the **More** menu in its header.
3. Choose **Export as**.
4. Select **PDF** or **Markdown**.

PDF is suited to sharing a finished, fixed-layout copy. Markdown keeps the text in a lightweight format that can be edited in many other apps.

## Copy a document

Choose **Copy page** from the same menu. Lunaris converts the document to Markdown and places it on your clipboard. Paste it into a message, notes app, or another editor.

To send several documents into one PDF, use [Export Workspace Content to PDF](/guides/tools-and-extensions/compile-to-pdf) instead.

You can also choose **Open in** to start a new ChatGPT or Claude conversation with the document. If the document is too long to include in the link, Lunaris copies it to your clipboard before opening the service.
