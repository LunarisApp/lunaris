# Teamarbeit

Erstellen Sie eine Teamorganisation, wenn mehrere Personen zusammenarbeiten. Wählen Sie **Geteilt** für ein Teamhandbuch oder ein Projekt, das alle Mitglieder der Organisation finden sollen. Wählen Sie **Privat**, wenn der Zugriff auf ausgewählte Mitglieder beschränkt sein soll.

- [Teilen Sie einen Arbeitsbereich](/de/teams/share-a-workspace) mit der Organisation oder einzelnen Mitgliedern.
- [Bearbeiten Sie Dokumente gemeinsam](/de/teams/edit-together), setzen Sie die Arbeit nach Verbindungsabbrüchen fort und prüfen Sie den Dokumentverlauf.
- [Vergleichen Sie Rollen](/de/reference/roles-and-permissions), bevor Sie Zugriffsrechte vergeben.
- [Verwalten Sie die Organisation](/de/administration), wenn Sie für Mitglieder, Abrechnung oder Sicherungen zuständig sind.
