# Work offline

Lunaris saves edits on the device you’re using. What you can open offline depends on the workspace and what has already downloaded.

- **Local** workspaces live in the browser profile or desktop app where you created them. Work there offline and return to the same app to open it later.
- **Private** and **Shared** workspaces sync when connected. You can edit resources that are already available on the current device. An uploaded file may need to download separately before its preview works offline.

## Before you disconnect

1. On each device you plan to use, sign in to the same account and data region.
2. Open the cloud workspace while online. Open the documents and uploaded files you will need.
3. Select the sync indicator and wait for downloads to finish. Open any important attachment to confirm its preview loads.

You can [install the web app](/reference/platform-availability) from a supported browser. Its Local workspaces and cache still depend on browser storage.

## While offline

Keep working in any available workspace. Edits to cloud workspaces queue locally. Invitations, billing, cloud backups, and the assistant need a connection. If a workspace shows **Workspace unavailable offline**, return to the workspace list and choose one already available on this device.

## After reconnecting

Leave Lunaris open while changes upload and incoming changes download. After important edits, verify **Settings → Local Data → Upload Queue** is empty before clearing browser data or switching devices. **Last Synced** is the time of the previous successful sync. Use the queue to see whether your latest edits are pending.

If a change stays queued or a workspace still cannot open, follow [Recover local work and sync](/reference/recover-local-work).
