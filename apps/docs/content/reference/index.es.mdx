## Resolver un problema

- [Recupera el trabajo local y la sincronización](/es/reference/recover-local-work) si falta contenido sin conexión, hay cambios pendientes de subir o piensas borrar los datos.
- [Resuelve problemas de cuenta y acceso](/es/reference/account-and-access) si no puedes iniciar sesión, aceptar una invitación o abrir un espacio de trabajo.
- [Resuelve problemas de extensiones](/es/reference/extension-problems) si falta una herramienta o una vista de recurso, está desactivada o no está disponible sin conexión.
