# Customize a workspace

Extensions are enabled per workspace. Keep a writing workspace focused on drafts and sources, or add a board and a drawing to a project workspace. When you open a resource, its extension supplies the resource view.

- [Manage extensions](/customize/manage-extensions) to enable a built-in tool, install a marketplace release, or get back to existing extension content.
- [Set up a project with notes, files, and a board](/customize/tools-for-a-project).
- [Choose how to connect an AI tool](/customize/connect-ai), from sending a single document to granting scoped access.
- [Connect an AI app with MCP](/customize/mcp) to search and work with resources you approve.
- [Build your own extension](/developers/extensions) if your workflow needs a new tool or resource type.
