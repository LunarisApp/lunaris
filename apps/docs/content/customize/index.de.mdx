# Arbeitsbereich anpassen

Sie können Erweiterungen für jeden Arbeitsbereich einzeln aktivieren. Verwenden Sie einen Arbeitsbereich für Entwürfe und Quellen oder ergänzen Sie ein Projekt um ein Board und eine Zeichnung. Wenn Sie eine Ressource öffnen, stellt ihre Erweiterung die passende Ressourcenansicht bereit.

- [Verwalten Sie Erweiterungen](/de/customize/manage-extensions), um ein integriertes Werkzeug zu aktivieren, eine Version aus dem Katalog zu installieren oder bestehende Inhalte wieder zu öffnen.
- [Richten Sie ein Projekt mit Notizen, Dateien und einem Board ein](/de/customize/tools-for-a-project).
- [Wählen Sie, wie Sie ein KI-Werkzeug nutzen](/de/customize/connect-ai). Sie können ein einzelnes Dokument senden oder gezielt Zugriff gewähren.
- [Verbinden Sie eine KI-App über MCP](/de/customize/mcp), damit sie in den freigegebenen Ressourcen suchen und damit arbeiten kann.
- [Entwickeln Sie eine eigene Erweiterung](/de/developers/extensions), wenn Sie ein neues Werkzeug oder einen neuen Ressourcentyp benötigen.
