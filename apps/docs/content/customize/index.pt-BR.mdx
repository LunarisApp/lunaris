# Personalizar um espaço de trabalho

As extensões são ativadas por espaço de trabalho. Dedique um espaço de escrita a rascunhos e fontes ou acrescente um quadro e um desenho ao espaço de um projeto. Ao abrir um recurso, sua extensão fornece a visualização do recurso.

- [Gerencie extensões](/pt-BR/customize/manage-extensions) para ativar uma ferramenta integrada, instalar uma versão do catálogo ou voltar a acessar conteúdo existente.
- [Monte um projeto com notas, arquivos e um quadro](/pt-BR/customize/tools-for-a-project).
- [Escolha como usar uma ferramenta de IA](/pt-BR/customize/connect-ai), desde enviar um documento até conceder acesso a recursos específicos.
- [Conecte um aplicativo de IA via MCP](/pt-BR/customize/mcp) para buscar e trabalhar com os recursos que você autorizar.
- [Crie sua própria extensão](/pt-BR/developers/extensions) se precisar de uma nova ferramenta ou tipo de recurso.
