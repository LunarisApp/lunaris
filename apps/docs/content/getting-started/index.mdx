# Start Here

## 1. Open Lunaris

Go to [web.lunaris.app](https://web.lunaris.app). Sign in, create an account,
or choose **Continue as Guest** to try it without signing up.

An account lets you create workspaces that sync across devices. Guest work stays
in this browser. Creating an account does not convert existing Local workspaces
to cloud workspaces. Export important local work before clearing browser data.

## 2. Open your organization

Lunaris starts with a **Personal** organization: a home for your own workspaces.
To work with other people, [create another organization](/guides/account-and-organizations/manage-organizations).

Open **Welcome to Lunaris** to try the example writing, board, and drawing. You
can edit or delete them. This example workspace is Local, so it does not sync.

## 3. Create a workspace

On **Recent Workspaces**, choose **Create → Create empty**. Enter a name and
choose where to keep your work:

- **Local:** only in this browser or app on this device.
- **Private:** synced across devices, with access for people you choose.
- **Shared:** synced and available to everyone in the organization.

Select **Create Workspace**, then open its card. Local workspaces cannot be
changed to Private or Shared later.

## 4. Start writing

Select **Create new file**, choose **Rich Text**, and name your document.
Start typing. Lunaris saves your changes automatically.

Next: [format your writing](/guides/writing-and-editing/create-and-format-documents)
or [learn your way around](/getting-started/navigate-lunaris).
