# Manage Local Data

Open **Settings → Local Data** to see what Lunaris stores on this device. This page shows sync health, last sync time, storage usage, and the upload queue.

## Check storage and pending work

**Data Used** estimates how much browser storage Lunaris occupies. **Upload queue** shows changes waiting to reach the cloud. A non-empty queue is normal while offline or during a transfer.

If sync has paused after an account, permission, or temporary error, correct the cause and choose **Retry Sync**.

## Before deleting local data

The danger zone contains two different actions:

- **Discard Pending Uploads** permanently discards every pending upload. Any unsynced data contained in those uploads is lost.
- **Purge All Local Data** wipes Lunaris data and downloaded files from this browser, then reloads the app. Synced cloud data downloads again; local workspaces and unsynced changes cannot be recovered from the cloud.

Use neither action as routine cleanup. First reconnect, sign in, and allow sync to finish. If you must purge, create an organization backup where possible and separately preserve any local-only work.

In the web app, clearing site data or letting the browser remove stored data can also delete local work.
