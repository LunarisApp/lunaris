# Write and organize a project

A workspace can hold a draft and the resources it depends on, such as a PDF brief or a task board. Give the project its own workspace when you need a distinct set of tools or a different access policy.

## Keep sources beside the draft

1. Open the workspace and use **Add folder** to make a *Sources* folder.
2. With the folder selected, choose **Add file** to create or import the resources that belong there. Otherwise, Lunaris adds the new resource at the workspace root.
3. Create the draft with **Add file → Rich Text**. Drag resources onto a folder to move them there, or between rows to change their order.
4. Select the draft and a source to open them in tabs. Drag one tab toward the edge of the editor to view both side by side. On smaller screens, open resources one at a time and use Back to return to the workspace.

Choose **More → Focus Mode** in the active resource to hide surrounding controls. Press **Esc** to bring back the workspace. Focus Mode requires enough screen space for the full workspace layout.

## Find a resource again

Use **Search** or press **⌘/Ctrl + K** to find workspaces, resources, matching document text, and commands. Use the field above the workspace tree to filter the current workspace by name. If text from a file or extension does not appear, search for its resource name.

## Recover a deleted resource

Open **Trash** in the workspace sidebar, select the resource, and choose **Restore**. You need edit access. Deleted resources stay in Trash for 30 days unless someone chooses **Delete now**. The Trash only covers resources within the workspace.
