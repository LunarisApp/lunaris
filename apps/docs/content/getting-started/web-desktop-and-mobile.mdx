# Web, Desktop, and Mobile

## Web app

Open [web.lunaris.app](https://web.lunaris.app) on your computer, phone, or tablet.
No installation is needed. Supported browsers also let you install the web app
or add it to your home screen.

On smaller screens, select a resource to open it full screen. Use Back to return
to the workspace.

## Desktop preview

Lunaris also has a desktop preview. If you have it installed, you can use your
organizations and cloud workspaces there. It also supports approved connections
from local AI apps through **Settings → Local Data → Agent access**.

The preview requires manual updates; it does not update itself automatically.
Local work in your browser does not automatically appear in the desktop app.

## Mobile

Use the web app on your phone or tablet. A dedicated mobile app is planned.

## Use another device

Private and Shared workspaces sync through your account:

1. Sign in with the same account and data region.
2. Open the organization and workspace while online.
3. Open any files you need and wait for downloads to finish before going offline.

Local workspaces stay in the browser or app where you created them. They do not
sync, even after signing in elsewhere. Avoid clearing local data while you have
Local workspaces or unsynced changes.

See [Work Offline](/guides/offline-and-sync/work-offline) for more help.
