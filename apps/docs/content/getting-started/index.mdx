# Start here

Create a workspace, write a short note, and check that it opens offline. You can try the whole walkthrough as a guest.

## 1. Choose where the workspace lives

Open [Lunaris](https://web.lunaris.app) and select **Continue as Guest**, or sign in. In **Recent**, choose **Create → Create empty**. Name the workspace *First notes* and pick a visibility:

- **Local** for this walkthrough or work that should stay in this browser or desktop app. Guests use Local.
- **Private** for synced work you want on multiple devices or want to share with selected organization members.
- **Shared** for synced work the whole organization should be able to open.

Choose **Local** for this walkthrough. Signing in later leaves this workspace on the original device. If you need cross-device access for a real project, choose a cloud workspace when you create it. See [Workspace visibility](/reference/workspace-visibility) for the full comparison.

Select **Create Workspace** and open its card in **Recent**. Your organization groups your workspaces and controls membership. A workspace is where the files, documents, and other resources for a project live.

## 2. Write and reopen a note

1. Choose **Add file → Rich Text** in the workspace sidebar.
2. Name the document *Offline check* and write a sentence. Lunaris saves the edit as you type.
3. Close the document tab, then select *Offline check* in the sidebar. Confirm the sentence is still there.
4. With Lunaris open, disconnect from the network, add another sentence, and reopen the document again. Both sentences should appear. Reconnect when you are done.

If you use a cloud workspace for this exercise, open it online first and wait for downloads before disconnecting. Follow [Work offline](/personal/work-offline) to prepare the files you need and confirm your edits sync on reconnect.
