# Developers

- [Build extensions](/developers/extensions) to run a workspace tool or add a resource type and its views. Start with the [extension quickstart](/developers/extensions/quickstart) for a working standalone panel.
- [Use the CLI](/developers/cli) to query workspaces and resources from a terminal or automate tasks in scripts.
- [Manage extensions](/customize/manage-extensions) if you already have a release and want to install or update it in a workspace.
