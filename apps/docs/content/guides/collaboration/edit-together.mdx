# Edit Together

Editors can work in the same cloud workspace from different browsers. Lunaris updates shared content in real time when everyone is online and merges changes made while someone was offline.

## Start collaborating

1. [Invite the other people](/guides/collaboration/invite-and-share) and give them edit access.
2. Open the same workspace and resource.
3. Edit normally—Lunaris saves and syncs in the background.

Rich-text documents, Kanban boards, and Excalidraw drawings all use collaborative data. Changes from another editor appear without manually saving or refreshing.

## Avoid surprises

- Give **Viewer** access to anyone who should review without editing.
- Watch the sync indicator before closing a browser after important changes.
- If you lose your connection, continue working and let Lunaris sync after you reconnect.
- Use [Version History](/guides/writing-and-editing/version-history) to inspect recorded changes to a document.

Lunaris merges concurrent edits, but two people can still make an unexpected editorial decision in the same passage or task. Agree on ownership for sensitive sections and review the result together.
