# Folders and the Workspace Tree

The workspace sidebar lists your folders and resources: documents, boards, drawings, and uploaded files.

## Add folders and resources

Use **Add folder** or **Add file** at the top of the tree. If a folder is selected, the new resource is created inside it; otherwise it is added at the workspace root.

You can also open a folder's menu to add content directly inside it.

## Rearrange the tree

Drag an resource to change its order or move it into a folder. Drop it between rows to reorder it, or onto a folder to move it inside. You can also drag with the keyboard when using keyboard navigation.

Open an resource's menu to:

- rename or delete it;
- duplicate supported document resources;
- copy its path or direct URL;
- add another resource inside a folder.

Select several resources when you want to delete them together. Copy and paste can duplicate supported document resources, but not folders or every uploaded file type.

Use **Collapse all** when a large tree becomes difficult to scan, or search at the top of the tree to filter by resource name.

## Recover deleted resources

Deleting a resource from the sidebar moves it and its contents to **Trash** for
30 days. To recover it:

1. Open **Trash** from the workspace sidebar.
2. Select the resources you want back.
3. Choose **Restore**.

You need edit access to restore resources. **Delete now** permanently removes the
selected resources and their contents. This cannot be undone. Trash does not
restore a deleted workspace or organization.
